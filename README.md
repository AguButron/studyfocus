# StudyFocus

Un espacio virtual para estudiar de forma ordenada con tus amigos, sin necesidad de estar juntos físicamente. Entras a una sala 3D, llevas a tu personaje hasta una mesa, te sientas y estudian juntos.

No es un juego para pasarlo bien: el personaje y la sala existen para dar la sensación de compartir una mesa de estudio.

## Principio de diseño

Cada función debe ayudar a estudiar o a sentirse acompañado al hacerlo. Si distrae del estudio, no entra: nada de puntajes, niveles ni misiones.

## Estado

En desarrollo, fase 1. El avance está en [docs/ROADMAP.md](docs/ROADMAP.md).

## Objetivo del MVP

Creo una sala, le paso un link a un amigo, ambos caminamos con nuestro personaje, nos sentamos en la misma mesa y vemos un temporizador de estudio compartido.

- **Servidor:** TypeScript, Node.js y Socket.IO
