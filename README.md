# StudyFocus

Una sala virtual 2D donde entras con tus amigos, mueves a tu personaje, te sientas en una mesa y estudian juntos.

## Estado

En desarrollo, fase 0. El avance está en [docs/ROADMAP.md](docs/ROADMAP.md).

## Objetivo del MVP

Creo una sala, le paso un link a un amigo, ambos caminamos con nuestro personaje, nos sentamos en la misma mesa y vemos un temporizador de estudio compartido.

## Tecnologías previstas

- **Cliente:** TypeScript, Phaser y Vite
- **Servidor:** TypeScript, Node.js y Socket.IO

## Requisitos para desarrollar

- Git
- Node.js 24 o superior

Las instrucciones para ejecutar el proyecto se agregarán en la fase 1, cuando haya código que ejecutar.
